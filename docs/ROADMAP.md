# Roadmap: demo and beta

Status: **plan** (2026-10-07). Dates are targets, not promises. If behind, cut scope (see the cut list), not sleep.

Code isn't the bottleneck; **art is** (models, maps, VFX, UI, animations). Plan around that.

## Timeline

| Dates | Goal |
|---|---|
| Oct 7 – Nov 1 | Demo content: Bill VFX, real models, character select, one polished level |
| ~Nov 10–15 | **Demo video everywhere** (see [marketing/demo-launch.md](marketing/demo-launch.md)), then read the feedback |
| Nov 15 – Dec 1 | Ghost, Clown, map 2, saving, lobby flow |
| **Dec 1** | **Feature freeze.** After this: only bug fixes, polish and levels |
| Dec 1 – 12 | Test with friends, fix bugs, mobile pass |
| **~Dec 15–19** | **Beta release.** Not Dec 23–24: launches break, so be around to fix it before holiday traffic peaks |

The demo video ends with the beta date and "join the group to get notified" (Roblox has no wishlists).
