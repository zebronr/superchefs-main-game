# Demo launch

Goal: release a demo on Reddit (and TikTok/Shorts) as soon as possible, and **not** get called an Overcooked ripoff again (that happened with last year's demo).

The rule: **show the difference in the first 3 seconds.** The superskills are the difference, so the whole demo and every clip are built around them.

## Demo scope

| In | Out (later) |
|---|---|
| 1 polished level, with the dining room and tables visible in the shot | More levels |
| Gecko, Bill, Penguin, and maybe the Alien (all coded) | Ghost, Clown, Fire type, Octopus |
| Character select so players can try each | Crates, saving, progression |
| Customers at tables taking orders | Patience and tips (nice to have) |

## Where to post

1. **r/robloxgamedev first**, with the **clean gameplay cut** (~30 s, readable gameplay, short captions explaining each superskill). Devs there give real feedback, and heavy edits can feel like an ad to them.
2. **TikTok, YouTube Shorts, Reels, r/roblox** with the **TikTok edit**. Max hype.
